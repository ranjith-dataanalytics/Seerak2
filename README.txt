IMPORTANT: The images are referenced from the repository root, matching the current GitHub repository structure shown in your screenshot.

HOW TO UPDATE YOUR EXISTING GITHUB REPOSITORY
1. Extract this ZIP.
2. In your repository, click Add file > Upload files.
3. Upload/replace index.html and style.css.
4. Also upload the new pages: services.html, about.html, process.html.
5. Keep the image files in the repository root. If they are already there, you do not need to upload them again.
6. Commit changes.

All pages share the same navigation and contact section. Menu items open separate pages. Contact details are arranged in a 2-column x 2-row grid on mobile and desktop.
